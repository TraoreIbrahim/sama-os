titre: Les liens dans un document
resume: Voir où mène un lien avant de l'ouvrir
mots: lien adresse site internet url hypertexte cliquer ouvrir arnaque raccourci docs

**Poser un lien** : choisissez le texte, puis le bouton **Lien** de la petite barre (ou **Insertion › Lien…**). Tapez l'adresse : « wave.com » suffit, Sama ajoute https://. Une adresse de courriel devient un lien de courriel.

**Un clic sur un lien n'ouvre rien tout de suite.** Une carte dit d'abord **où il mène vraiment** : le nom du site, en clair. Sama prévient aussi :

- si le texte affiché annonce un autre site (« wave.com » écrit, mais le lien mène à « wave-bonus.xyz ») ;
- si le lien est raccourci (bit.ly…), donc sans qu'on voie où il va ;
- s'il n'est pas chiffré (http) ;
- si son adresse a une forme inhabituelle.

Ensuite : **Ouvrir**, **Copier**, **Modifier** ou **Retirer** (le texte reste, sans le lien).

Les arnaques passent souvent par un lien dans un document reçu. Au moindre doute, n'ouvrez pas : demandez à la personne par un autre moyen. Voir aussi [Reconnaître une arnaque](sama:article/securite/arnaques).
