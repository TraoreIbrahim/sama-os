Le code affiché à gauche du Pouls (**FR**, **DYU**, **WO**, **SW**…) indique la méthode de saisie en cours.

**Changer de méthode** : cliquez sur ce code et choisissez dans la liste, ou appuyez sur **Méta + Espace**.

**Lettres du julakan** (méthode DYU, clavier AZERTY) :

- **AltGr + R** donne ɛ, **AltGr + P** donne ɔ
- **AltGr + J** donne ɲ, **AltGr + M** donne ŋ
- avec **Maj** en plus : Ɛ, Ɔ, Ɲ, Ŋ

**Ajouter une langue** : [Réglages › Clavier](sama:reglages/langue/clavier), puis « Ajouter une disposition ».
