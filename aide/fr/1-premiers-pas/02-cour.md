Toutes vos applications sont dans la **Cour**.

1. Cliquez sur **l'éléphant**, à gauche de la Natte, ou appuyez sur la touche **Méta** (celle avec le logo Windows sur beaucoup de claviers).
2. Commencez à écrire le nom de ce que vous cherchez : « docs », « fichiers », « réglages »… La Cour trouve aussi les réglages.
3. Appuyez sur **Entrée** pour ouvrir le premier résultat, ou cliquez sur celui qui vous convient.

**Astuce** : dans un Espace, un clic droit sur une application ouverte permet de l'épingler à cet Espace, pour la retrouver directement dans la Natte. Voir [Épingler une application à un Espace](sama:article/espaces/epingler).
